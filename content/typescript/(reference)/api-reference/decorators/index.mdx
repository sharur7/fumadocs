Every NitroStack capability is declared with a decorator. This section lists each one with its options and an example, grouped by what it does.

TypeScript uses PascalCase decorators from `@nitrostack/core` (`@Tool`, `@Module`, `@Injectable`). Python uses snake_case decorators from `nitrostack` (`@tool`, `@module`, `@injectable`). Where both exist, the signature is shown in TypeScript and Python tabs.
