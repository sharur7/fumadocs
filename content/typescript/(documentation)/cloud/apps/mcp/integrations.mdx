**Integrations** in the MCP menu shows whether this server can deploy on push. **Connection status** tells you whether the GitHub App is installed for your organization and whether auto-deploy is set up for this app.

<Screenshot src="/images/cloud/mcp-integrations.png" alt="The app Integrations page showing that the GitHub App is installed and auto-deploy is not configured" />

- **Deploy settings** opens [Deployments](/docs/cloud/apps/mcp/deployments), where you link a repository to turn on auto-deploy.
- **Organization integrations** opens [Integrations](/docs/cloud/integrations), where you install or manage the GitHub App.
