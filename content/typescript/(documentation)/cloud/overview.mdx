## Deploy your first app

You deploy from the dashboard: create an app, link your repository or upload a zip, and add your environment variables. The steps, including how to prepare a TypeScript or Python project, are on the [Dashboard](/docs/cloud/dashboard#deploy-from-the-dashboard) page.

## What runs where

An **organization** is the account boundary. Apps, members, API keys, the GitHub connection, Studio access, and payment methods all belong to the organization.

An **app** is one product. It can have an MCP server, a hosted chat, or both. The server is what MCP clients call; the chat is a website that calls that server's tools. Each app has its own plan: Free includes 500,000 requests a month, and Pro is billed per app. See [App billing](/docs/cloud/apps/billing).

**NitroStudio** is separate. It's the desktop app, and organization [API keys](/docs/cloud/api-keys) sign it in. [Studio management](/docs/cloud/studio-management) decides who on the team can use it and which models they can call.
