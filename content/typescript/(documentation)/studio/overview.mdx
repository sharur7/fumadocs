NitroStudio is a desktop app for working on MCP servers. Open a project and Studio starts your server, connects to it the way an AI client would, and shows everything it offers: tools, resources, prompts, and tasks. From there you can call a tool by hand, chat with a model that uses your tools, generate and run test cases, and deploy to [NitroCloud](/docs/cloud/overview) without leaving the app.

Studio works with any NitroStack project, and with other MCP servers too. While you edit your code, it reloads the server on save, so what you see always matches what you wrote.

All platforms need at least 4 GB of RAM.
