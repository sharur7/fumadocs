The syntax you reach for most, ready to copy, for both languages. Pick TypeScript or Python in any section and the rest of the page follows. Each card links to its full guide.

TypeScript snippets assume `import { ... } from '@nitrostack/core'`, and Python snippets assume `from nitrostack import ...`. Install with `npm install @nitrostack/core` or `pip install nitrostack`. A Python server is configured with a `.env` file and `ServerConfig`; there is no `nitro.yaml`.

```ts
import { ToolDecorator as Tool, z } from '@nitrostack/core';

@Tool({
  name: 'get_product',
  description: 'Look up a product by ID',

}
```

```ts
@Middleware()
export class Timing implements MiddlewareInterface {
  async use(ctx: ExecutionContext, next: () => Promise<any>) {
    const start = Date.now();
    const result = await next();
    ctx.logger.info('done', { ms: Date.now() - start });
    return result;
  }
}

@UseMiddleware(Timing)
```
