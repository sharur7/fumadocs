NitroStack ships two SDKs: [`@nitrostack/core`](https://www.npmjs.com/package/@nitrostack/core) for TypeScript and [`nitrostack`](https://pypi.org/project/nitrostack/) for Python. Both build MCP servers the same way. You group features into [modules](/docs/getting-started/core-concepts/modules), declare tools, resources, and prompts with decorators, inject services with [dependency injection](/docs/getting-started/core-concepts/dependency-injection), and run every call through the same [request pipeline](/docs/getting-started/core-concepts/request-lifecycle).

The APIs follow each language's conventions. TypeScript uses Zod schemas and class decorators such as `@Tool`; Python uses Pydantic models and decorators such as `@tool`. Pick the language your team works in; everything else in these docs applies to both.
