Welcome to NitroStack. This guide details the architecture and capabilities of the framework designed for building production-grade [Model Context Protocol (MCP)](/docs/getting-started/core-concepts/mcp-basics) servers.

NitroStack is a high-performance framework engineered for scalability and maintainability, with SDKs for [TypeScript](/docs/getting-started/core-concepts/server-concepts) and [Python](/python/sdk/quick-start). It provides a robust architecture for developing MCP servers, offering advanced features such as [dependency injection](/docs/getting-started/core-concepts/dependency-injection), [modular organization](/docs/getting-started/core-concepts/modules), and [type-safe tooling](/docs/sdk/tools) out of the box.

## Why NitroStack?

**For enterprise development.** NitroStack enforces consistent patterns across large teams, is built on proven architectural patterns for long-term maintainability, and follows a security-first design with robust [authentication and authorization](/docs/sdk/auth/overview) mechanisms.

**For AI integration.** NitroStack is built specifically for the [Model Context Protocol specification](https://modelcontextprotocol.io). It delivers structured data and [interactive UI components](/docs/getting-started/core-concepts/widgets) to AI agents, and efficiently manages [tools](/docs/sdk/tools) and [resources](/docs/sdk/resources) for complex agentic workflows.
