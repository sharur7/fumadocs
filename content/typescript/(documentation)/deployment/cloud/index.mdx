You can run a NitroStack server anywhere that runs a container or a Node.js process. Each guide below covers deployment, secrets, health checks, and logs on one platform.

Every platform needs the same three things from your server. It must listen on all interfaces (`HOST=0.0.0.0`) and on the port the platform expects (`PORT`). It should run over HTTP only (`MCP_TRANSPORT_TYPE=http`). And the platform should check the built-in `/mcp/health` endpoint to know when the server is ready. [Deploy with Docker](/docs/deployment/docker) explains each of these settings.

## Comparison

A rough guide to choosing:

| Platform | Best for | Cost | Scaling |
| :-- | :-- | :-- | :-- |
| AWS ECS | Enterprise | $$$ | Excellent |
| Google Cloud Run | Serverless containers | $$ | Automatic |
| GKE / AKS | Large scale | $$$ | Manual |
| DigitalOcean | Simplicity | $$ | Manual |
| Heroku | Quick deploy | $$ | Easy |
