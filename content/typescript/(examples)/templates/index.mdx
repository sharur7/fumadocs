## Template names

Pass these names to `--template`:

| Template | TypeScript (`nitrostack-cli init`) | Python (`nitrostack-py init`) |
| :-- | :-- | :-- |
| Starter | `--template typescript-starter` | `--template python-starter` |
| OAuth 2.1 | `--template typescript-oauth` | `--template python-oauth` |
| Pizzaz | `--template typescript-pizzaz` | `--template python-pizzaz` |
| Enterprise Search | `--template typescript-enterprise-search` | Not available |
| Code Mode | `--template typescript-code-mode` | Not available |

Leave out `--template` to choose one interactively.
